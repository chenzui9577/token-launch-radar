TOKEN LAUNCH RADAR

Pre-token protocols, priced by their token-bearing peers. Snapshot facts only — no invented signals.

Implied value is a peer comparison built from the sealed DefiLlama snapshot: category median market-cap / TVL of protocols that already record a token, adjusted for 7-day TVL momentum, time running with no token, and chain reach. It is an estimate of what a launch could be worth if the record stayed as it is — not a prediction that a token will launch, and not financial advice.
